    Conexiones API

    Las claves viajan directo desde este navegador a cada proveedor (Anthropic, OpenAI, Google, Groq), sin servidor intermedio. Por defecto quedan solo en memoria: al cerrar o recargar la pestaña se pierden.

    Una suscripción de chat (Claude Pro, ChatGPT Plus, Gemini Advanced, etc.) no incluye acceso a la API: necesitás claves de API con crédito o cuota propia.

    Desactivado por defecto. Si lo activás, las claves se guardan sin cifrar en el localStorage de este sitio: cualquier script que corra en el mismo origen (por ejemplo, otra página tuya publicada en el mismo dominio de GitHub Pages) puede leerlas. No lo actives en un dispositivo compartido. Al desactivarlo se borra la copia guardada al instante.

    Ajustes

    Los cambios aplican a la próxima operación: una ronda o transcripción en curso sigue con la configuración con la que arrancó.

    Ronda

    Evita que el mismo rol enmarque siempre la discusión.

    Acuerdos, desacuerdo clave, decisión recomendada y próximo paso. Si está apagada, el último panelista cierra con propuesta, desacuerdos y próximo paso.

    Modelos de debate

    Algunos modelos cuentan el razonamiento interno dentro de este límite; si ves respuestas TRUNCADAS, subilo.

    Transcripción

    Se usa vía generateContent. Existe gemini-3.5-transcribe, pero su API no está verificada acá: si lo probás y falla, volvé a gemini-3.5-flash-lite.

    Ninguna transcripción es perfecta: revisá el texto antes de enviarlo.

    Respaldo

    Orden: Claude → OpenAI → Gemini → Groq, sin repetir proveedor en un mismo turno. La tarjeta muestra el rol, la etiqueta EMULADO y el proveedor/modelo real.

    Ojo: el respaldo manda el contexto y la conversación a otro proveedor y consume más cuota/crédito. Además, un rol emulado no es un debate real entre modelos distintos.

    Tiempos y reintentos

    Solo para límite de uso (429) y errores del proveedor (5xx). Si el proveedor pide esperar más de 10 s, se corta y se avisa en lugar de esperar en silencio.

    Audio

    Groq (free) y OpenAI aceptan hasta 25 MB; Gemini, ~20 MB por pedido. Al llegar al límite la grabación se corta y te aviso.

    Apagado por defecto. Nunca se envía solo si cambiaste de sala, cancelaste o hay una ronda en curso.
